# Bike-Sharing Hourly Demand Estimator

Course project for DevOps and MLOps. The app estimates hourly bike rental demand  
from historical date, hour, and weather inputs. It stores no business data.

## Functions

- Hourly demand prediction: estimate rentals per hour for one scenario.
- Scenario comparison: compare two scenarios that differ only in the hour.
- Error evaluation: compute residual and absolute error for a prediction.
